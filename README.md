# Hackerthon 🦈

A dynamic web-based platform for managing and showcasing hackathon events.

## Overview

Hackerthon is a comprehensive event management website designed to provide participants with all the information they need about the hackathon, including registration, schedules, tracks, speakers, FAQs, and prize information.

## Features

- **Registration** - Easy online registration for participants
- **Event Schedule** - Clear timeline of all hackathon events and activities
- **Tracks** - Multiple competition tracks and categories
- **Speakers** - Featured speakers and industry professionals
- **Prizes** - Prize pool and reward information
- **FAQ** - Common questions and answers
- **About** - Event information and mission

## Project Structure

```
├── index.html          # Main landing page
├── about.html          # Event information and details
├── register.html       # Registration form and process
├── schedule.html       # Event timeline and schedule
├── tracks.html         # Competition tracks and categories
├── speakers.html       # Featured speakers and bios
├── prizes.html         # Prize information and rewards
├── faq.html            # Frequently asked questions
├── style.css           # Main stylesheet
└── script.js           # JavaScript functionality
```

## Technologies Used

- **HTML5** - Structure and markup
- **CSS3** - Styling and responsive design
- **JavaScript** - Interactive features and functionality

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/sammyharrison58/hackerthon.git
```

2. Navigate to the project directory:
```bash
cd hackerthon
```

3. Open `index.html` in your web browser to view the website
